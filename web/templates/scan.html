Score arbitrary text for prompt-injection risk. Runs locally in the Worker — no Groq call, no API key, sub-50ms.

How it's built

TF-IDF (word + character n-grams) feeding a logistic regression, trained on labeled payloads from this project's own red-team traces and cross-validated. It's exported from the trained Python model and reimplemented faithfully in the Worker — the JS port was checked against the Python pipeline on real samples before being trusted, with zero measurable difference in the scores.

What "risk" means

low (score < 0.3), medium (0.3–0.7), high (≥ 0.7). See the findings for how it performs against Meta's Llama Prompt Guard 2 on the same benchmark, and the method page for how the training data was built and validated.
